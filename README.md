# MERN Product Management

A full-stack Product Management application built using the MERN stack with JWT authentication, role-based authorization, product CRUD operations, image uploads, and a React frontend.

## 🚀 Live Demo

### Frontend
https://mern-product-management-h9yh.vercel.app

### Backend
https://mern-product-management-jva6.vercel.app

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- React Router
- Axios
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Express Validator
- Multer
- ImageKit

### Deployment
- Vercel
- MongoDB Atlas
- ImageKit

---

## ✨ Features

### Authentication
- User Registration
- User Login
- JWT Access Token
- JWT Refresh Token
- HTTP-only Refresh Token Cookie
- Logout
- Protected Routes
- Automatic Access Token Refresh

### Authorization
- User and Admin roles
- Admin-only product operations
- Protected CRUD APIs

### Product Management
- Create Product
- View All Products
- View Product by ID
- Update Product
- Delete Product
- Product validation

### Image Upload
- Image upload using Multer
- Images stored using ImageKit
- Image URL saved in MongoDB
